# 手机回收站与页面导航

## 当前权威路径

- Room v7 `recycle_entries` 是删除恢复信息的唯一索引；整部小说仍只有一份日常数据库，不创建数据库备份。
- 章节、大纲（含子节点）、角色、世界观与对应关系/历史沿 `LocalAuthoringStore` 的事务执行删除，同事务记录删除前后的完整受影响集合。关系编辑保留未删除关系的 ID，只把实际移除的关系收进回收站。
- 已持久化的手机章节/大纲草稿在丢弃前先记录恢复内容，再关闭草稿文件；文件已被清理时仍能通过回收内容恢复。编辑器中尚未提交的修改不属于持久化草稿。
- 作品库删除仍然只移除本机作品。回收项保存本机副本、待同步队列、冲突、已停止的建档记录及导入包引用；导入包在永久删除或到期清理时才删除。其他设备上的作品不会因此被删除，排除下载记录持续生效。

## 恢复和永久删除

- 保存期限为删除时起 **168 小时**；`now >= expiresAt` 拒绝恢复。启动、读取回收站和删除操作清理过期项；设备离线不会延长期限。
- 资料恢复检查删除后的当前内容、关联对象、同一关系是否重建、建档记录与草稿空位；发生后续修改、缺失依赖、同 ID 重新导入或同步冲突时拒绝覆盖。
- 活跃的写作或建档任务阻止删除/恢复，需要作者先取消任务。恢复后的历史记录不重新启动模型任务。
- 本机恢复保留原正文、版本与关系。对需要同步的资料使用稳定删除 mutation ID 对应电脑回收项，通过有序 `recycle_restore` / `recycle_purge` 命令同步。恢复中的快照保留至电脑确认，丢回执重试同一命令；PC 拒绝时保留本机恢复内容与可查看的失败信息。
- 永久删除有独立确认对话框，清除回收内容；不会覆盖或清理后来新增的同名/同 ID 内容。已经恢复、等待同步的条目禁止再次恢复或永久删除。

## 平台边界

手机独立完成本机删除、查看、恢复、期限校验与永久删除，不要求 PC 正在运行。回收快照本身不跨端复制：手机回收站列出从本机删除的内容；电脑删除的内容在电脑回收站恢复。移动端资料删除产生的同步命令在连接 Gateway 后同步执行，双方各用自己的事务快照恢复。立项关闭、取消任务、清理缓存不伪装成删除作者资料。

## 入口

书架顶部明确展示“回收站 · 删除后保留 7 天”。作品顶部“全部页面”可搜索正文、大纲、助手、作品信息、角色、世界观、伏笔、叙事治理、建档与导出、回收站，并直接打开目标页面；页面搜索仅过滤明确的导航标题与描述，不推断 Agent 的业务意图。

## 验证

测试使用 Android API 35 模拟器、内存 Room 数据库、随机测试包与 MockWebServer；未对用户小说或数据库执行删除测试，未复制真实数据库。覆盖关系与正文恢复、恢复冲突、导入包与队列保留/到期清除、稳定同步 ID 与丢回执、PC 冲突、7 天临界值、v3→v7 迁移，以及 145% 字号下搜索导航。真机未连接，本次不声称完成真机验收。
