# 司命 3.5.3

本版集中改进 Windows 桌宠的衣装、动作与交互，修复从屏幕边缘偷瞧切换到任务姿势时的顶部裁切。

## 贴边与菜单修复

- 任务开始、唤醒或拖动退出偷瞧时，等待实际窗口宽高恢复后再显示完整姿势。恢复期间保留原大小的探头画面，不临时缩小角色，也不将完整姿势画入紧凑窗口。
- 处理原生窗口回执与画布尺寸更新的不同先后顺序；连续停靠、切换任务及调整大小不会被旧回执覆盖。恢复失败会提示重试，不假装完成。
- 右键打开菜单后，再次右键角色或菜单内即可收起；保留 Esc 和窗口内菜单外左键关闭方式。右键收起不会触发说话或拖动。

## 衣装与动作

- 新增“朱红常服”，与“经典长袍”共用站立、读书、坐睡、贴边偷瞧和被拎起五种姿势。可从桌宠右键菜单或设置页切换并保存，默认仍为经典长袍。
- 两套衣装共用同一动作调度与渲染路径，只加载当前衣装；切换时释放旧资源，迟到的素材加载不会盖回新衣装。
- 优化眨眼节奏、轻点点头、轻微歪头和读书抬头。注视以角色脸部为中心，随实际大小、气泡位置和左右探头重新计算，减少领口挤压与突兀回弹。
- 被拎起时采用专门的悬垂姿势，水平拖动带来小幅整体倾斜；停下后回正，不持续甩动袖子。连续拖动只处理最新坐标，避免旧移动请求积压。

## 显示与性能

- 改进高刷新率屏幕上的动画帧节奏；布局、气泡换边和左右镜像改变时立即刷新画面与点击区域。
- 高 DPI 放大时提高绘制精度，缩小时保留缓冲区，避免反复分配；不因画质变化改变角色大小或脚底位置。
- 遵循“减少动态效果”偏好，页面隐藏时停止动画，恢复时不重放过期的点击或拖动反应。

## 范围与升级

- 桌宠是 Windows 桌面端功能；Android 与 Gateway 同步版本号，不创建悬浮窗。本次不改变写作、建档、任务执行或手机独立运行的业务契约。
- 动作仍采用完整姿势直接切换与轻微整体变形，不包含复杂肢体补间或 Cubism 工程导出。
- Windows：`Siming-Setup.exe`、`Siming-Setup.sha256`。
- Android：`Siming.apk`、`Siming-apk-sha256.txt`。
- Gateway：`ghcr.io/teangtang1122/siming-ai-gateway:3.5.3`，支持 amd64 与 arm64。

覆盖安装前请保存工作并退出司命及使用同一安装目录的相关进程。小说数据沿用原数据目录，现有桌宠设置保留。Windows 安装包尚无代码签名，可用随包 SHA-256 核对完整性。
