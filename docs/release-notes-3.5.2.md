# 司命 3.5.2

本版新增删除恢复与页面搜索导航，集中修复 API 调用、编辑器状态和多章节建档的可靠性问题。

## 7 日回收站与页面导航

- 作品、章节、大纲、角色、世界观、立项资料、助手对话等作者资料删除后进入回收站，保留 7 天（168 小时），可恢复或立即永久删除。关联版本和资料随对应删除记录保留。
- 恢复会检查原有标识、关联依赖和后续修改；遇到冲突时停止恢复，不覆盖新内容。到期或永久删除后无法通过回收站恢复；升级前已彻底删除的数据无法补回。
- PC 与手机分别保留本机删除记录。电脑删除在电脑恢复，手机删除在手机恢复；回收快照不随作品同步传输。手机移除整部作品仅影响本机副本。
- PC 可按 Ctrl/⌘+K 搜索页面、按功能浏览并选择作品；手机作品页提供可搜索页面目录。跳转前检查未保存内容，PC 页面支持浏览器前进与后退。

## API 请求与中断恢复

- 按实际接口地址、协议和任务统一生成请求参数。官方 DeepSeek 的纯文本请求与建档默认关闭思考；硅基流动 Chat Completions 建档默认关闭思考。显式参数优先，其他地址不按模型名称套用这些设置，CLI 自身配置保持独立。
- 修复 DeepSeek 在同一工具事务中切换思考模式后回放不一致的问题，保留实际返回的思考字段，不生成虚假思考内容。
- 工具流响应经完整校验后才交付执行。连接中断时在有界次数内重新请求本步完整响应，避免把说明文字误当成正文恢复检查点，或执行半份工具参数。
- 统一管理传输重试，避免 SDK 与应用重复重试；思考流活动不会误报为空闲，输出截断不会标记为成功。
- 立项助手遇到格式合法但未开放的工具时整批拒绝，并反馈给同一模型有限纠正；错误提示不再误导为上下文容量故障。
- 未填写上下文且没有已知容量资料的自定义 API，临时默认由 256K 改为 **128K（128,000 token）**。精确配置优先；这不是模型实际容量保证，小窗口模型仍需填写服务商公布的值。

## 本地模型与多章节建档

- 固定建档每一步核算输入、工具格式、输出预留和安全余量。本地模型冷启动先加载运行实例，再使用实际模板、分词器和窗口计量。
- 接近容量时从完整原章、已读档案、已有候选及最新工具事务重建请求，减少重复历史状态；原始调用记录继续保留。必需资料仍超限时明确暂停，不截断故事内容或自动提交完成。
- 明确要求建档保存单独调用。模型把“保存＋读取”或“两次保存”放在同一步时整批零执行，收到错误回执后由同一模型重新选择；同类拒绝累计三次后暂停，保留已有候选。多个只读工具仍可同批执行。
- 修复多章节任务在上述错误后立即停止、没有纠正机会的问题。该规则与章节序号无关，不存在“只能成功第一章”的限制。
- 加强建档完成与取消状态校验：完成须以实际写入及章节摘要为依据，取消的任务不能通过迟到操作重新启动，错误章节标识不会扩大为整书范围。

## 编辑器与手机一致性

- 章节读取、历史恢复和保存响应绑定实际作品、章节及编辑修订，避免切换页面后迟到请求覆盖当前内容。
- 后台刷新保留未保存正文与大纲修改；保存只清除对应提交的脏状态，删除成功后清除已删除编辑器的残留提醒。
- 对齐手机角色配置、大纲人物关联、工具拒绝回执、请求参数及建档检查点契约。手机直连 API 和本机回收站可独立运行，不要求 PC 客户端在线。
- 平台差异继续明确记录：手机使用保守容量估算，PC 受管理本地模型使用实际分词器；手机独立建档没有 PC 的逐候选手工编辑模式。详见[跨端能力与边界](https://github.com/teangtang1122/siming-ai/blob/v3.5.2/docs/mobile-pc-parity.md)。

## 验证范围

- 已完成相关后端、前端与 Android 单元回归，以及隔离数据库、真实前端页面和 Android 模拟器验证。
- 三章连续建档回归覆盖第二章出现混合工具调用、纠正后继续完成第三章，以及纠正耗尽后保留候选。此部分使用可控模型响应，不代表所有真实模型都会纠正成功。
- 本地 Qwen3.8 27B Q3 此前已在 **64K 上下文**下跑通立项、写作、作者保存与建档等完整流程；本次还验证了真实本地建档失败任务保留候选后续跑完成。仍不承诺每轮成功，模型输出须由作者审阅。
- API 协议回归使用模拟响应及已保存故障记录；供应商持续超时、缺少结束帧或输出不合契约仍可能导致暂停。不能把请求修复视为所有 API 的速度或全流程成功保证。

## 下载与升级

- Windows：`Siming-Setup.exe`、`Siming-Setup.sha256`。
- Android：`Siming.apk`、`Siming-apk-sha256.txt`。
- Gateway：`ghcr.io/teangtang1122/siming-ai-gateway:3.5.2`，支持 amd64 与 arm64。

跨设备使用时请同步升级 PC、Android 与 Gateway。Windows 覆盖安装前保存工作并退出司命及使用同一安装目录的相关进程；文件仍被占用时，安装器会停止并保留旧程序。小说数据沿用原数据目录。安装包尚无 Windows 代码签名，可用随包 SHA-256 核对完整性。
