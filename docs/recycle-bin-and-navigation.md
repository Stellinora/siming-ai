# 回收站与页面导航

## 找回误删的数据

普通删除会将支持的作品资料移入「回收站」。删除时间起保留 **7 天（168 小时）**；恢复不会延长原删除记录的保留期。

1. 打开「回收站」。也可以在「页面导航」中搜索回收站。
2. 根据名称、资料类型、所属作品和删除时间找到记录。
3. 点击「恢复」。恢复成功后，可以进入对应作品继续使用。

删除整部作品时，恢复以整部作品及其保存的关联资料为单位。删除单项资料时，保留其关联数据，恢复前校验依赖和冲突。

如果所属作品也被删除，先恢复作品。若恢复会覆盖后续修改，操作会明确报错，并保留回收记录，不能通过反复点击强行覆盖现有数据。恢复历史记录不会自动启动旧的写作或建档任务。

## 立即永久删除

在回收站选择「永久删除」，确认后立即清除该回收记录保存的内容。这一步不可撤销。满 7 天的记录不再允许恢复，并由程序自动清理；设备关闭期间无法运行清理，下次使用时处理过期记录。

回收站使用现有数据库，不会为每次删除复制一份整库备份。SQLite 清理后的空间可被后续数据复用，数据库文件不一定立即变小。

## 更快找到页面

电脑端的「页面导航」支持搜索页面名称，并按功能分组；也可使用 `Ctrl+K`（macOS 为 `⌘+K`）打开。需要作品上下文的页面使用明确选择的作品，跳转前仍遵守未保存编辑的确认流程。

手机端从书架进入回收站；作品中的页面目录用于直接找到写作、大纲、角色、世界观、建档和导出等功能。

## 使用边界

- 该功能保护升级后进入回收站的删除。升级前已物理删除的数据不会凭空出现，需从已有备份或导出文件找回。
- 回收站保存作品资料，不作为模型凭据、诊断日志、任务历史或整机设置的备份。
- 手机在本机独立保存、删除和恢复资料，恢复不要求电脑客户端正在运行。
- 手机「移除本机作品」与删除其他设备上的作品不是同一个操作。跨设备同步仍遵守原有冲突保护；回收站的保留期限也不能代替同步冲突处理。
- 各端回收站显示各自删除的记录，回收快照不随普通作品同步传输。电脑删除的记录在电脑回收站恢复；手机删除资料后发出的恢复、永久删除命令按顺序同步到电脑。同步失败时会显示错误并保留待处理状态。
