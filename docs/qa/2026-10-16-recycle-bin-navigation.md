# 7 日回收站与页面导航验收

## 需求与边界

- 普通作者数据删除保留 168 小时；回收站恢复及立即永久删除。
- 提供清晰可发现的回收站和页面导航入口，保留未保存编辑提醒。
- PC、API/CLI/MCP 共用原权威删除领域路径；Android 在本机独立运行。
- 不在用户真实数据库做删除测试，不创建用户整库副本，不调用模型 API。

## 实现

PC 在原数据库的 `recycle_bin_entries` 表中保存删除事务的实际行变更，包括外键级联和关联字段变化。删除与快照在同一事务提交，不为每次操作遍历复制整库。恢复校验原 ID、依赖、当前字段及唯一约束；冲突不覆盖后续内容，整笔恢复回滚。七天边界以服务端时间为准，过期清理通过启动、后台维护和回收站访问触发。永久删除清除快照；运行租约、凭据和后台任务不因恢复重新执行。

覆盖作品、章节、大纲、角色、世界观、立项资料/会话、助手对话/记忆、持久化草稿、技能、角色关系及出场/变化记录。关联版本随主体保留。诊断日志、执行历史、模型凭据与配置清理不属于回收站。

手机使用 Room 回收表和同一保留期限。资料恢复依赖真实本地数据，跨设备恢复命令通过稳定 ID 的有序 outbox 同步；同步拒绝或丢回执时保留恢复快照。整部作品移除沿用仅移除本机副本的边界，保留导入包和待同步数据供恢复。各端不共享回收快照目录，电脑删除在电脑恢复，手机删除在手机恢复。见 `docs/mobile-pc-parity.md`。

页面导航支持按页面名称检索、功能分组和选择作品。PC 使用真实 URL 跳转及 Ctrl/⌘+K；GUI 页签状态来自 URL，支持回退。手机作品页提供可搜索页面目录。新跳转入口执行未保存编辑检查。

## 实际浏览器验收

通过 Playwright CLI 操作构建后的真实前端及 FastAPI，端口 `127.0.0.1:8898`。数据目录限定在 `.build/recycle-ui-20261016`，运行程序 `.build/recycle-ui-smoke.py`；未连接用户运行中的司命服务。

1. 演示章节「第一章 · 归来的信」包含正文和一个版本快照。
2. 章节菜单删除，确认提示说明正文/历史/出场记录移到回收站。
3. 作品侧栏进入回收站，显示一条章节记录、删除和到期时间。
4. 点击恢复，跳转原章，正文和版本历史均恢复，真实章 ID 不变。
5. 修改正文但不保存，从页面导航跳转，出现未保存提醒；取消后仍在原页且编辑保留。
6. 搜索「建档」，结果定位作品建档；确认离开后进入 `?view=cataloging`，浏览器回退返回原章节。
7. 再次删除章节，从回收站永久删除，二次确认后显示成功，API 回收站列表为空。

验收发现删除当前脏编辑成功后仍保留 dirty 登记，已修正并增加成功/失败分支回归。重新构建后，用「导航状态验收」章节实际执行编辑、删除、进入回收站，确认不再出现残留的未保存提醒；删除失败仍保留编辑。
